## Default Permission

Lets the app's pages start, watch, pause, mask and stop a GaiaDesk support session: start-help, stop, set-paused, set-masks and status.

#### This default permission set includes the following:

- `allow-start-help`
- `allow-stop`
- `allow-set-paused`
- `allow-set-masks`
- `allow-status`
